Statuses the API understands — applications: SUBMITTED · IN_REVIEW · REFERRED · APPROVED · DECLINED; loans: CURRENT · ARREARS · CLOSED; repayment frequencies: MONTHLY · FORTNIGHTLY · WEEKLY.

Keep the exercises working

  • Include at least one application that is already APPROVED — the workbook uses it to demonstrate a 409.
  • Include a loan with a small balance (a few thousand) so the "payment larger than the balance" exercise returns 422 rather than succeeding.
  • Include a loan with arrears_days above zero, so ?in_arrears=true returns something.
  • Five or more customers, so pagination with page_size=2 has several pages.
